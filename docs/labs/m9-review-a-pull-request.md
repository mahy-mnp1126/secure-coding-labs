# Module 9: Review a pull request (closing exercise)

Your instructor will open the pull request `feature/statement-download` in the training repository. It adds an endpoint that lets a customer download a monthly statement.

In pairs, review it for 20 minutes with the Module 9 checklist (the same items are in this repository's pull request template). For each problem you find, write down:

- what is wrong, and which checklist item it breaks,
- how you would fix it,
- the test that would fail if the problem came back.

Then compare findings with the class.
